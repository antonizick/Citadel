🔄 Self-Update / Recovery

          
Backup, snapshot current code, then update core system files from a deployment package

        

        

          
Update from Package URL

          

            This wizard performs four steps automatically:
            (1) create a full data backup,
            (2) snapshot current code into a deployment package,
            (3) download the specified package and overwrite core files (data and config are always preserved),
            (4) update Python dependencies and restart Citadel.
